# 轻笺

Windows 桌面便签与笔记工具，支持富文本、提醒、AI 新闻、模型资讯、录音转写及普通文档导入。

当前源码版本：**0.10.12 测试版，Windows x64**。本机已完成构建、安装和隔离验收；其他电脑及干净 Windows 的兼容性仍待验证。

## 安装与升级

本仓库已同步 0.10.12 源码与说明。**本次没有创建 0.10.12 GitHub Release，也未向 Git 仓库提交安装包**。已有 0.10.3 发布包不能代表当前源码。安装包可由维护者提供，或按下文自行构建。

1. 保存草稿、结束录音，并从托盘“退出”旧版。不要覆盖仍在运行的程序。
2. 升级前导出重要内容；完整恢复还需要备份应用数据目录与单独配置的音频/语音目录。
3. 运行 Windows x64 安装包并选择安装目录。建议安装在数据盘的 `轻笺\app`，数据目录规则见下文。
4. 启动“轻笺 V1”。需要 Microsoft Edge WebView2 Runtime；缺少运行环境的干净系统尚未全面实测。

## 日常使用

- 便签／笔记用 **Ctrl+S** 保存；支持 Ctrl+B、Ctrl+Z、Ctrl+Y。
- 顶部放大镜按标题搜索，方向键选择，Enter 打开。
- 切换栏目保留本次运行中的子页面、选中条目、编辑草稿与滚动位置；完整退出后导航位置回到默认，已保存内容仍保留。
- 待办／已完成依据提醒状态，与正文复选框独立。
- 列表卡片固定手柄可拖到外侧快捷标签，点击打开原记录。
- 标题栏提供最小化、最大化／还原、关闭。关闭通常进入托盘；完全退出使用托盘菜单。
- 退出可清理可放弃的后台模型资讯及连接测试；录音、未保存草稿和正式处理任务仍有保护提示。

### 窗口与贴边隐藏

“设置 → 通用”分别配置轻笺置顶与贴边隐藏，两者独立。

启用贴边隐藏后，普通窗口实际接触所在显示器的左、右或上边缘，拖动松手 **500 毫秒**后隐藏；底部不触发。隐藏无可见把手，可将鼠标移到原窗口对应的边缘范围唤出，也可从托盘唤出。鼠标离开窗口 500 毫秒后再次隐藏，返回或重新拖动取消计时；拖离边缘解除停靠。

拖到顶部不使用系统贴靠最大化；最大化／还原由标题栏按钮控制。最大化状态不自动隐藏。录音、关键弹窗和拖动期间保留操作保护。多显示器／缩放的核心逻辑已测试，所有真实硬件组合仍待验证。

## 普通文档导入

在“便签”或“笔记”点击 **导入**：

**选择文件 → 解析预览 → 修改标题和目标栏目、勾选条目 → 确认导入 → 查看编辑**。

支持多选，预览前后原文件均不修改；确认前不写数据库。整个过程在本地执行，不调用在线模型。

| 格式 | 处理规则 |
| --- | --- |
| TXT | UTF-8 / UTF-8 BOM，保留换行；错误编码明确拒绝 |
| Markdown | .md / .markdown；保留基本标题、段落、列表、待办与强调，复杂结构提示降级 |
| Word | .docx；基本标题、段落、列表与强调，表格转可读文字；不支持 .doc、宏或加密文件 |
| JSON | 单条对象、数组、items 数组、body 别名；支持按实际字段映射标题／正文 |

JSON 示例：

```json
{"title":"示例标题","content":"正文内容"}
```

```json
{"items":[{"title":"标题一","body":"正文一"},{"content":"缺省标题正文"}]}
```

正文必须为非空字符串。非法条目会显示原因；部分有效时需明确选择仅导入有效条目。复杂嵌套 JSON 可以主动选择作为一条格式化文本导入，外部 ID 与提醒、置顶等状态不继承。

图片与附件不自动下载；地址或说明保留为文字，HTML／脚本不执行。Word 的复杂排版、图片、页眉页脚等会提示不支持。

上限：**单文件 10 MiB；每批 20 文件、30 MiB、200 条；每条正文 500 KiB**。另有嵌套、节点、ZIP 解压等资源限制。解析可取消，事务保存开始后需等待完成。

确认前自动创建 `.qjbackup` 内容备份，选中条目一次事务保存，失败整批回滚。生成新内部 ID，不覆盖已有条目。查看结果沿用未保存草稿处理规则。

详见 [导入说明](docs/DOCUMENT_IMPORT_GUIDE.md) 和 [JSON 示例](docs/import-examples)。

## 新闻与模型资讯

### AI 新闻

读取 **AIHOT 精选**，不是 AI 日报。每个北京时间自然日首次启动，先显示缓存，再后台尝试一次自动更新。失败也记为当日已尝试；重启、切页、托盘唤出不自动重试。用户主动点击“刷新”可再次获取。

按来源实际最新日期显示，只保留一份最新有效缓存。来源仍是前一日时保持真实日期；不假定固定更新时间。分页、去重、逐条校验；无效条目单独跳过，失败、空响应或无效整批不能清空缓存。单条原文未提供发布时间时，不编造时间，来源日期与原文时间分开显示。

### 模型资讯

来源为 **橘鸦 AI 早报的公开网站／RSS**，不声称直连微信公众号或覆盖所有限免模型。

进入页面先显示本地缓存，切页不重复获取或筛选。首次补齐当月；每自然月最多一次当月全量筛查；每次启动一次增量检查，追踪未处理期数并补查遗漏。已有处理记录保留，避免升级后重筛历史。

明确截止且过期的资讯从展示列表移除，未知期限保留“期限待确认”。“检查更新”显示真实获取、筛选进度和结果；成功状态约三秒后隐藏，失败可重试、展开原因。检查成功代表已检查当前可访问来源的追踪范围，不代表全网限免覆盖。没有全局模型资讯任务横幅。

## 模型与语音配置

### 在线文字模型

“设置 → 模型”填写供应商的 Base URL、模型 ID、API Key，保存后测试。密钥使用 **Windows 凭据存储**，不放入数据库、导入备份或源码。费用和服务能力由供应商决定。

连接测试与正式任务独立，有超时、取消和脱敏错误状态。测试显式非流式，只有有效正文回答才成功，思考内容不算回答；不同供应商的输出预算与思考参数按适配协议处理。接口兼容性以实际测试为准。

### 本地 SenseVoice 与录音

“设置 → 语音”选择非 C 盘语音工作目录，使用“一键检测并安装”；准备 Python、依赖、SenseVoice 和 VAD 资源后，等待实际转写检测通过，再在录音中选择本地引擎。下载需网络；安装包不包含这些模型。

当前为 Windows x64 CPU 方案，不保证 ARM64 原生或 GPU 自动适配。至少预留 4 GB 磁盘，长录音需更多资源。只有 C 盘的机器无法使用当前非 C 盘语音目录流程。

在线语音地址、模型与密钥单独配置。使用在线转写或授权在线回退会发送音频至所选服务。

录音支持麦克风与系统声音、暂停继续、转写校对、纪要和保存为笔记。详见 [录音使用说明](AUDIO_WORKFLOW_GUIDE.md)。

## 数据与备份

程序在创建 SQLite 和 WebView 前解析数据根目录，优先级为：

1. 环境变量 `QINGJIAN_DATA_ROOT`：必须是绝对路径。
2. EXE 同目录 `data-root.txt` 的第一行：绝对路径，或相对 EXE 的目录。
3. 安装目录名称为 `app`：使用其父目录下 `data`。
4. 未指定且不符合上述规则：`%LOCALAPPDATA%\SHUSHIN\Qingjian`。

例如安装在 `D:\Apps\轻笺\app`，默认数据为 `D:\Apps\轻笺\data`；不将维护者的路径写死给所有用户。

数据根目录包含 `qingjian-v1.sqlite3` 及 WAL、应用配置与资讯缓存、内容备份、WebView 数据和应用临时目录。音频／语音设置可指定独立目录，应一并备份。Windows 凭据与系统管理文件仍由系统管理，不能宣称所有数据均迁至数据盘；改变 Windows 用户或 LOCALAPPDATA 可能影响原有凭据标识，不要明文导出密钥。

更换目录不会自动安全迁移旧数据。先完全退出，使用 SQLite backup API 生成一致快照，验证内容与配置，再切换；保留旧目录。不要在程序运行中只复制主数据库而忽略 WAL。

“设置 → 文件”的 `.qjbackup` 恢复与普通导入独立，支持选择条目及同 ID 策略。**内容备份不含录音原文件及录音会话历史**，不是整目录备份。重要音频应另存，转写和纪要可先保存为笔记。

## 开发者构建

Windows x64、Node.js 22.12+、Rust、WebView2 Runtime。默认 MSVC 构建需 Visual Studio C++ Build Tools 和 Windows SDK；也可使用已配置的 GNU / MinGW 工具链，本次本机交付使用 GNU target。

```powershell
npm ci
npm run build
cargo test --release --manifest-path src-tauri/Cargo.toml
npm run tauri -- build --bundles nsis
```

GNU 构建需安装对应 Rust target 与 MinGW 工具链：

```powershell
npm run tauri -- build --target x86_64-pc-windows-gnu --bundles nsis
```

安装包输出在 `src-tauri/target/[target-triple/]release/bundle/nsis`。使用提交的依赖锁文件。构建前可将 `CARGO_HOME`、`RUSTUP_HOME`、`CARGO_TARGET_DIR`、npm 缓存、`TEMP` / `TMP` 指向自己的数据盘；下载工具的缓存位置也应核查。

仓库不包含用户数据、模型资源、Windows 凭据、构建缓存或维护者的本机安装／迁移／清理脚本。重新构建不承诺与交付安装包逐字节一致。第三方组件及模型遵循各自许可；本次未新增项目开源许可授权。
