# 轻笺 0.10.12 普通文档导入

在“便签”或“笔记”点击“导入”，选择一个或多个文件。预览后可修改标题、目标栏目、勾选条目，再确认导入。未确认不会写入数据；原文件保持不变。

- TXT：UTF-8 / UTF-8 BOM，保留换行。不支持 GBK，需先转换编码。
- Markdown：标题、段落、列表、待办、强调；表格转换为可读文字。图片及链接保留说明或地址，不自动下载。HTML 作为文字，不执行。
- DOCX：基本标题、段落、列表和强调，表格转换为文字。复杂排版、图片、页眉页脚等在预览提示。旧版 .doc、宏文件及加密文件不支持。
- JSON：支持单个对象、数组、items 数组及 body 别名；正文必须为非空字符串。可按实际字段映射标题/正文。复杂嵌套可主动选择作为一条格式化文本导入。外部 ID、提醒及其他状态不导入。

部分数据无效时，需明确勾选“仅导入有效条目”。全部无效无法确认。处理期间可取消；事务保存开始后请等待完成。

限制：每个文件 10 MiB，每批最多 20 个、合计 30 MiB，最多 200 条；每条正文 500 KiB。另有结构、节点及 DOCX 解压上限，超限明确提示。正文预览最多 1200 字，实际符合上限的完整正文会保存。

每次确认前在应用数据根目录 backups 中生成“文档导入前-….qjbackup”。保存采用一次事务，失败整批回滚。备份不含录音原文件与转写历史；不替代完整数据备份。

导入完成可点击查看。查看结果时沿用未保存草稿处理规则；选择继续编辑会保留原草稿。导入内容可正常编辑、搜索、保存和重启读取。

.qjbackup 备份恢复仍在“设置 → 文件”，与普通文档导入独立。整个导入在本地完成，不调用在线模型。

同目录 JSON 示例均可直接导入；自定义字段示例选择 name 为标题字段、text 为正文字段。
