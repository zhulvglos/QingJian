# 0.10.17 测试版

## 本次仓库同步

包含 0.10.12 之后的现有交互改进及 0.10.17 查看模式修复：

- 一级导航恢复新闻、便签、笔记、设置四项文字；二级导航保留已办等入口。
- 全部内容、已勾选、未勾选、提醒四模式互斥；筛选不改写完整正文，筛选编辑保留未显示内容。
- 提醒独占正文区域，提醒草稿在本次运行保留，退出时保护未保存修改。
- 长标题进入完整多行编辑框，视觉换行不写入标题，结束编辑不隐式保存。
- 快捷标签紧凑显示、300ms 悬停向外展开、主题右键菜单及置顶状态协调。
- 列表导入/导出、资讯加入便签/笔记、自动备份管理及恢复预览。
- 顶部录音入口先打开工作区，用户明确开始才采集；整窗透明度各窗口只合成一次。

## 验证范围

本机 Windows x64：TypeScript/Vite 构建、61 项 Rust 测试通过；0.10.17 NSIS 安装包构建和本机安装已完成。实际 WebView2 验证四模式、嵌套任务、筛选编辑与保存、提醒草稿保护、三档字号、长标题保存/重启重读；回归页面位置、未保存正文、快捷标签/置顶、自动备份及短录音保存播放。

当前显示环境外的 Windows DPI、多显示器、旧 WebView 的标题兼容回退、干净电脑仍未全面实测。本轮未复测物理鼠标的 500ms 拖边循环，未调用真实在线模型。源码可构建不代表已验证任何新电脑的运行环境。
