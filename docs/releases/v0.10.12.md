# 0.10.12 测试版

本次同步从 0.10.3 到 0.10.12 的累计修复，当前本机安装已为 0.10.12；没有创建对应 GitHub Release 或上传二进制安装包。

## 累计变化

- 数据根目录在 SQLite / WebView 创建前解析，支持环境变量与配置文件；保持 Windows 凭据保护。
- 模型测试、资讯后台任务具有取消、超时、类型与结束状态，退出清理可放弃任务，保护正式任务和未保存内容。
- AIHOT 精选：北京时间每日首次启动一次自动尝试，失败不自动重复；手动刷新、分页去重、逐条容错、缓存保护与真实来源日期。
- 模型资讯：缓存优先、按启动增量与自然月全量策略追踪，切页不重复筛选；页内简洁状态及真实数量、失败重试，不显示全局任务横幅。
- 本次运行内保留栏目子页面、选中条目、草稿与滚动位置。
- 窗口最大化／还原按钮、普通窗口置顶、实际贴边隐藏、无标识边缘唤出；首次及再次隐藏共用 500 毫秒。
- TXT、Markdown、DOCX、JSON 普通文档导入，预览、字段映射、批量事务与导入前内容备份。

## 0.10.12 验证

56 项 Rust 测试、TypeScript/Vite 和 NSIS 构建成功。安装版通过 10 组导入主流程与 16 类错误分支、真实 Windows 文件多选／取消、写入失败回滚、编辑／搜索／重启、草稿保护、源文件不变和用户内容摘要保持。测试数据均隔离，不调用真实模型。

尚未验证另一台干净 Windows、真实加密 Word、各种第三方复杂 DOCX、所有多屏缩放硬件组合；本轮未重新播放私人录音或验证真实在线模型。回退备份与脚本已校验，未实际回退已验收版本。
