# 0.10.3 测试版

Windows x64 小范围试用。普通用户下载附带的安装程序，无需构建源码。

## 变更

取消开发机固定旧目录自动发现；隔离 SenseVoice 运行环境、依赖和缓存并记录资源来源；保留已有用户明确保存的配置。包含此前便签、笔记、快速搜索、快捷标签、提醒、资讯、录音转写及纪要和品牌图标。

## 验证与限制

全新空目录下载全部语音资源、依赖安装、样例转写、约28秒双路录音转写、重启再次转写通过。后续同机独立账户验收报告覆盖升级、测试内容与配置保留通过；部分功能仅作后端检查。

未完整验证：干净 Windows、其他电脑兼容性、真实断网回退、两小时录音、磁盘耗尽及当前安装版全部语音流程。

已知问题：安装成功后旧进度文字可能残留；识别存在同音词错误。当前本地语音须选择非 C 盘目录，只采用 x64 CPU 方案。在线功能需自行配置兼容服务和密钥。
